 CAuthenticationBehaviourAuthentication behaviour with a typed denial payload. On the server, returning success = false from ValidateClientPayload ships the supplied TDenial to the client (via AuthenticationDenialPacket) before the socket closes. On the client, onDeniedByServer fires with the decoded reason so user UI can react.
 CAuthenticationDenialAckClient -> server ack acknowledging an AuthenticationDenialPacket so the server can immediately close the socket without waiting for the ack timeout.
 CAuthenticationDenialPacketServer -> client packet describing why a connection is about to be closed. The client decodes reason via the active AuthenticationLayer.OnDenialReceived override (typed by AuthenticationBehaviour<TRequest,TDenial>) and acks with AuthenticationDenialAck. The server closes the connection on ack OR after the authenticator's timeout, whichever fires first.

 CNetworkTransformDefaultStrategyDefault adaptive sync strategy. Straight motion is detected first and handled by the linear fallback paths; anything else is reconstructed along locally fitted circular arcs, covering motion with roughly constant curvature over one send interval: orbits, turns, arches, projectile arcs and spline-like paths. Rotation is continued at constant angular rate whenever the segment meaningfully rotates.

On its own this base class reconstructs skipped motion linearly; subclasses override TryReconstruct to shape it differently.
