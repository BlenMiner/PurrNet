AdaptiveSyncLevel adaptiveSyncLevel [get, set]
 How aggressively adaptive sync skips sends. Uses the built-in default strategy tuned for the level unless a custom strategy is injected via SetSyncStrategy; injected strategies keep their own tuning (see NetworkTransformSyncStrategy.ApplyLevel) and any level other than AdaptiveSyncLevel.Off activates them unchanged. Setting this at runtime re-initializes the sync stream locally; it is NOT replicated to other peers — set it everywhere yourself. Changing the value in the inspector during play mode does replicate, so all peers stay consistent while tuning.
