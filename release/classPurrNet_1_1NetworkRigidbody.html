void SetSoftParent (NetworkIdentity identity)
 Soft-parent this rigidbody to identity : its position, rotation and velocity sync in that identity's local frame, exactly as if parented there, but the Unity transform is left untouched — no real reparenting, no hierarchy sync. Overrides space while active. Pass null (or call ClearSoftParent) to revert. Linear and angular velocity are always relative to the parent Rigidbody's motion while this parent-local frame is active, so they remain valid derivatives for interpolation and extrapolation. With no sync parent, position and velocity remain in world/absolute space.

void PurrNet.NetworkRigidbody.ForceSyncFor ( float  seconds = -1f)

Opens a force-sync window. While the window is open, the controller bypasses the change thresholds and ships state every tick, and observers can query isInForceSyncWindow to adjust local correction behaviour. Opening the window also sends the current state reliably once.

Parameters
secondsWindow duration in seconds. Pass -1 (default) for a one-tick window.
