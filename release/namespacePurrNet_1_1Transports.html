enum PurrNet.Transports.FragmentDropReason : byte

Allocation-free-on-the-hot-path message fragmentation and bounded reassembly. Fragment loss is never recovered here: an incomplete message expires as a unit.

Header format: Unfragmented: [1 byte: 0x00] [payload] Sequenced: [1 byte: 0x02] [4 bytes: messageId] [payload] Fragmented: [1 byte: 0x01] [4 bytes: messageId] [4 bytes: totalLength] [2 bytes: fragmentStride] [1 byte: fragmentIndex] [1 byte: totalFragments] [payload]
