Detailed Description

Single entry point for turning a PrefabID (or a prefab reference) into PrefabData. Every runtime lookup goes through here so the resolution strategy can be changed in one place. Global prefabs live in the manager's provider; scene scoped prefabs come from the SceneRegistry<T> of the scene named by PrefabID.scope.
